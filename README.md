Database
This project uses a small, self-contained e-commerce dataset created for this task. It includes:
- customers
- products
- orders
- order_items
How to run
1. Install DB Browser for SQLite or use a SQLite extension in VS Code.
2. Open/create a database named Ecommerce_SQL_Database.db.
3. Open ecommerce_sql_analysis.sql.
4. Execute the complete script.
5. Run individual queries and compare the results with the output images.
You can also run it with the SQLite command-line tool:
sqlite3 Ecommerce_SQL_Database.db < ecommerce_sql_analysis.sql
SQL concepts covered
- SELECT, WHERE, ORDER BY
- GROUP BY and aggregate functions: COUNT, SUM, AVG
- INNER JOIN, LEFT JOIN, RIGHT JOIN
- Subqueries
- CREATE VIEW and querying a view
- CREATE INDEX and EXPLAIN QUERY PLAN
Notes
- SQL dialect: SQLite 3.39+ (RIGHT JOIN support was added in SQLite 3.39).
- Currency values are illustrative INR amounts, not real business transactions.
- The dataset is synthetic and was created for learning and demonstration.
- The screenshots show query results generated by executing the included SQL against the sample database.
